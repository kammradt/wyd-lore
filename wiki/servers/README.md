# Servidores privados

*Private servers.* Conteúdo de servidores privados, separado do canon oficial.

Ainda não há páginas aqui. Quando houver, cada página deve:

- usar `canon: private-server` no cabeçalho YAML;
- dizer o nome do servidor, o período em que esteve ativo e o link oficial dele;
- descrever só o que o servidor criou ou mudou (quests, itens, mapas, eventos novos), sem repetir o conteúdo oficial que já existe nas outras categorias.

# Passando Adicional para Arma Arch

> Guia rápido para transferir um adicional (add) para uma arma Arch no NPC Tainy, em Karden, usando a arma Ancient +9 de destino, uma arma Ancient +9 com o add desejado, um item +9 [D] ou [E] e 100.000.000 de gold. O processo pode falhar.

Nenhuma arma é boa o suficiente se não tiver um add considerável em sua base, para isso existe uma forma de deixá-la forte o suficiente.

Para realizar tal feito é necessário ter os seguintes itens:

* Arma desejada +9 (anct)
* Arma com o add +9 (anct)
* item [D] ou [E] +9
* 100.000.000 de gold

![Image](../../sources/feedback_kersef/data/images/22809-passando-adicional-para-arma-arch_img_0.jpg) ![Image](../../sources/feedback_kersef/data/images/22809-passando-adicional-para-arma-arch_img_1.jpg)

Vá ao NPC Tainy em Karden (gelo) e entregue os itens, mas lembre-se: a chance de falha não pode ser descartada.

Boa sorte!

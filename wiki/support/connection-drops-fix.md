# Correção de quedas de conexão no servidor

> **Fixing Server Connection Drops.** Addresses players being disconnected without reason due to IP conflicts and suggests switching network via a VPN such as Windscribe, with a tutorial video.

Atualmente, recebemos algumas situações de jogadores sendo desconectados do servidor sem nenhum motivo.

Esse problema está acontecendo por conflito com seu IP. Descobrimos uma possível solução para o problema. Você precisará alterar a VPN de rede para através desse tutorial (opção free para teste).

Video: <https://www.youtube.com/watch?v=2uyhuBLsyR0>

Download: <https://prt.windscribe.com/download>.

Qualquer novidade entre em contato com a equipe através do suporte e encaminhe seu feedback!

Estaremos te esperando!

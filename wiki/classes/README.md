# Classes

*Classes.* As classes jogáveis e suas skills.

| Página | English | Resumo |
| --- | --- | --- |
| [Personagens e Primeiras Impressões](overview.md) | Characters and First Impressions | Introduces the four classes (Transknight, Foema, Beastmaster, Huntress) and their many skill lineages. It also covers starting in the city of Armia, the Training Field for level 1 characters and basic mouse controls for moving and attacking. |
| [Skills](skills.md) | Skills | Explains how to learn skills from each class's skill master in Armia: Capitão Cavaleiros for TransKnight, Mestre Archi for Beastmaster, Foema Anciã for Foema and ForeLearne for Huntress. It describes the three skill lineages per class, the 24-skill limit, learning points, Aprender Arma and how to use the skill hotbar. |
| [Nona Skill (9th)](9th-skill.md) | Ninth Skill (9th) | Lists each class's 9th skills, bought from the NPC 9thMaster in Armia and learnable from level 201 by Celestial and Sub-Celestial characters for 255 skill points. A character can only learn the 9th of the same lineage as its 8th, learning it raises the mastery cap to 320, and it can be unlearned with the Círculo Divino Composto. |
| [10ª Skill](10th-skill.md) | 10th Skill | Describes the 10th skill for each lineage of the Foema, TransKnight, BeastMaster and Huntress classes, such as Proteção Absoluta and Invocação Final. Learning one requires all previous skills and 4000 fame points. |
| [11ª Skills](11th-skill.md) | 11th Skills | Lists the 11th skill book for each class lineage, such as Blaze Launcher, Life Wave Book and Bleeding Book, with their effects. Learning one requires level 281 or higher, 8,000 fame points and the skill's book. |
| [12ª Skills](12th-skill.md) | 12th Skills | Lists the 12th skills for every class lineage, learnable by Celestial characters above level 320 from the NPC Jazeg in Armia. The 11th skill of the same lineage is a prerequisite, and the cost is 12,000 fame (initially reduced to 1,200 for testing). |
| [Mudança de Classe e Mudança de Corpo](class-and-body-change.md) | Class Change and Body Change | Explains changing a character's class through the NPC Wooreunammu in Kefra (Sephirot of the target class plus 100kk) or with the Sephiroth Blessing item, which unlearns all Sephira skills. A body change uses the Sephiroth Protection item, and both items come from the Global server's monthly events. |

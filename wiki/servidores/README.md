# Servidores privados

Conteúdo criado por servidores privados, separado do canon oficial.

Ainda não há páginas nesta categoria.

<!-- notas -->
## Como escrever páginas de servidores privados

- Use `canon: private-server` no cabeçalho YAML.
- Diga o nome do servidor, o período em que esteve ativo e o site dele.
- Descreva só o que o servidor criou ou mudou (quests, itens, mapas, eventos novos), sem repetir o conteúdo oficial que já está nas outras categorias.
